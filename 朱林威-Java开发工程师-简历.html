  • 自研 Netty 二进制通信协议：设计 16 字节固定头（魔数/版本/序列化算法/消息类型/序列号）+ 变长体的自定义协议帧，解决 TCP 粘包半包与多消息类型分发； 基于策略模式实现 JSON/Java/Kryo/Protobuf 四种序列化可插拔切换，业务代码与序列化逻辑完全解耦，按场景灵活选择性能与可读性的平衡点。
  • 14 级 Pipeline 编排与三向集群路由：设计 HTTP → WebSocket 协议升级 → JWT 握手认证 → 心跳保活 → 消息编解码的完整 Pipeline； 跨平台自适应（Linux Epoll / Windows Nio）；实现基于 RabbitMQ Topic Exchange 的三向消息路由—— 同节点 Channel 直发、跨节点队列投递、离线消息 Redis Lua 原子标记，支持多 im-server 实例无状态水平扩展。
  • Redis 深度应用与 Lua 原子编程：手写 7 个业务 Lua 脚本解决高并发竞态—— Token 原子替换（先清后写，避免并发登录下的脏 Token）、二倍均值法红包随机分配（金额以分为单位避免浮点精度）、 朋友圈点赞/评论计数原子切换、缓存预热 SETNX 防穿透；综合运用五种数据结构；封装 Redisson 可重入锁 + SETNX 幂等锁双模式工具类，Pipeline 批量优化 + 随机 TTL 防缓存雪崩。
  • 红包/支付/打赏 —— 三层锁 + 补偿事务：设计 三层锁策略——MySQL 行锁（SELECT FOR UPDATE）串行化余额变更 + UPDATE 乐观余额校验二次兜底 + Redisson SETNX 幂等锁防 MQ 重复消费；转账场景按 userId 排序统一加锁顺序避免死锁； Redis Lua 原子抢红包 → MQ 异步到账；发红包扣款成功但写库失败时自动 Feign 退款补偿。
  • 朋友圈与 Canal 缓存一致性：帖子发布/点赞/评论/打赏完整闭环；选型 Canal + Cache-Aside—— Canal 监听 MySQL binlog 异步触发缓存删除，读请求 Cache-Aside 重建，避免双写不一致； Lua 脚本保证点赞/评论计数的原子递增；ZSet 实现热榜排行（Top 2000）。
